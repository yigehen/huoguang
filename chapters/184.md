# 第184章《沈姓旧名》

容姐旧屋的后门通向一条窄得只能侧身过人的夹巷。

沈昭把录音器塞进防潮袋，跟着周叙白往外撤。门外那两个人已经进了客厅。木地板被踩得轻响，随后是抽屉被拉开的声音。他们不是来抓人，至少第一目标不是。他们在找容姐留下的东西。

顾南枝最后一个离开，把后门虚掩回去。

巷子尽头连着一间废弃杂货铺。裴渡提前撬开卷帘门，几人钻进去时，灰尘被脚步掀起。外面追来的人没有立刻发现这道口，只在旧屋后门停了一会儿。

沈昭靠在货架旁，听见自己心跳很重。

第二个孩子还在海城。

这句话把所有线索都从旧案里拽回当下。不是死者，不是底片边缘，不是已经被水洗掉的人。她可能每天走在海城街道上，用另一个名字，另一张表，另一种白天身份活着。

顾南枝已经开始查。容姐旧屋录音里提到别追小昭这个名，说明小昭是诱导名。我们要反查沈姓旧名被谁覆盖过。

周叙白说，旧名册。

沈昭看向他。

周叙白低声解释，海临旧码头、城南北院、旧陪护站这些点都不是户籍终点。最后要能在白天活下去，必须进一次旧名册覆盖。周页借用，沈尾暂留，都指向名字被重新压过。

沈昭听完，忽然很轻地笑了一声。

周叙白，你现在说这些倒是越来越顺了。

周叙白脸色一白。

沈昭没有继续刺他。她知道他此刻不是敌人，可她也不能把那一层周家旧门从他身上完全剥开。每到一个新口，他总能从童年、母亲或周家边角里想起半句。他的半句，往往是别人丢了一生才留下的线。

夏宁握着那枚刻昭的发夹，忽然说，沈姓旧名不一定是她本来的姓。

顾南枝抬头。

夏宁脸色很白，声音却清楚。以前他们给我换名的时候，不是直接从原名换到新名。中间会压一个过渡名。那个名字不一定是真的，只是用来接页。小昭也可能是过渡名。

沈昭心里一动。

过渡名。

这就解释了容姐为什么说名是假的，人是真的。如果小昭只是过渡名，那么追这个名只会被带进错口。真正要找的，是谁曾被这个过渡名短暂覆盖，又被周页或沈页改写。

顾南枝很快从外线调到一份旧福利转接点名册扫描件。她把图片放大，指尖停在一列被涂黑的名字旁。

这里。海临码头白牌七之后，有一条临时接入记录。名字栏先写沈昭，后被划掉，旁边补了周页借用。最终落名不是沈，也不是周，而是一个完全不相关的白天姓。

沈昭盯着屏幕。

被划掉的沈昭两个字，写法很稚，像抄来的，不像正式登记。昭字最后一笔拉得很长，和发夹背面的刻痕方向相似。

这不是她。

可它借了她的名。

周叙白忽然说，母亲当年可能知道这个名字会害到你。

沈昭抬眼，冷冷看他。

他说得很慢。她说小昭不是她，可能不只是在保那个孩子，也是在阻止后来有人把这条线栽回沈家，栽到你身上。

沈昭没有立刻说话。

这个解释并不能减轻疼痛。它甚至更疼。因为如果何清如早就知道有人借沈昭这个名去补错口，那么沈昭七年前被迫离开、被周家旧案反复卷入，就不是单纯的感情断裂。她的名字，可能早在她知道以前，就已经被别人拿去做过一层纸上的壳。

裴渡忽然说，最终落名能看清吗。

顾南枝继续放大。扫描件边缘糊得厉害，但最后一栏有半个姓。不是沈，不是周。像是……许。

许。

沈昭脑中闪过许秋屏，许承安，也闪过北药房那条暂视为活的旧口。

周叙白的表情也变了。

如果最终落名是许，第二个孩子可能没有走周家公开口，而是被北药房或许家旧线压住过。

顾南枝立刻摇头。不能直接判定。许姓太多，扫描也不清楚。现在只能确定，小昭这个过渡名被划掉后，接了一个非沈非周的白天姓。

夏宁低声说，那她为什么还在海城。

因为有人没有把她送远。

沈昭看着那张模糊名册，声音越来越低。容姐说第二个孩子还在海城，不是说她被困在某个旧屋里，而是说她被放进了海城的白天人群里。她有现在的身份，有住址，有可能已经完全不知道自己是谁。

杂货铺外忽然亮起车灯。

追来的人终于摸到夹巷。

裴渡低声骂了一句。得走。

顾南枝把扫描件存好。可就在她收起手机的一瞬，屏幕上跳出一条匿名文件。

文件名很短。

旧名对照补页。

沈昭点开。

里面只有一张照片。照片里是一页手写对照表，最上方写着沈姓旧名暂压，右下角有容姐同样的红线结。

表格最后一栏被人用铅笔圈出。

小昭，非沈昭。现用名，许南音。

沈昭盯着那三个字，呼吸几乎停住。

许南音。

一个活着的名字。

车灯已经逼到门外。周叙白拉住她手腕，声音发哑。先走。

这一次，沈昭没有甩开。

因为她终于摸到了那个从镜头外被拿走的孩子，在白天世界里留下的第一道活痕。

【本章完】
