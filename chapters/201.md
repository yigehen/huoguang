# 第201章《互认段》

旧祠田仓的雨声没有停。

临时架起的冷白灯把仓内每一寸潮湿都照得清清楚楚。红线圈被顾南枝的外线一段一段剪下，分别装进证物袋；播放器、电池、随身听和那几卷磁带被摆在折叠桌上，像一排刚从黑暗里捞出来的骨头。

许南音坐在离红线最远的木箱边，肩上披着沈昭的外套。她的指尖还在发抖，却始终攥着那张线头朝外的照片。夏宁蹲在她旁边，没有碰她，只把一杯热水放在她脚边能看见的位置。

沈昭站在桌前，看着那卷被雨水泡开的磁带标签。

“不播给沈——南音 / 沈页互认段。”

几个字边缘洇开，像被人故意泡过，又没舍得彻底毁掉。

顾南枝摘下手套，声音压得很低：“许秋屏已经在赶来的路上。创伤医生也联系了。现在不能直接播放，但磁带必须先做物理检查，确认有没有夹口令、低频提示或者剪接段。”

裴渡把刚拆出的第三只铁皮箱放在桌下，箱口半开，里面是一排更小的带盒。每个带盒外都贴着旧标签，有的写着“入门”，有的写“停步”，还有一卷写着“互认前静音”。

周叙白看见那几个字，脸色变得更难看。

沈昭没有放过他眼神里的迟滞。“你又认得？”

“不是认得内容。”周叙白嗓音发哑，“周家以前祭祀前会有静音段，练小辈不许先开口。听见长辈问，必须等钟声过后再答。后来我才知道，有些人把这种家训方式拿去训练别的反应。”

“拿周家的规矩，训练被带走的孩子。”沈昭替他说完。

周叙白没有回避。“是。”

这一个字落得很重，像他终于不再把周家从句子里摘出去。

许南音忽然抬起头。她看着桌上的带盒，眼神不是完全清醒，更像有一小段记忆从雨声里浮了上来。“钟声。”

沈昭立刻转身，却没有走近。“你想起什么？”

许南音盯着仓库墙角的水痕，声音轻得几乎被雨盖住：“不是寺庙的钟。是铁的，敲一下，会有人说停。小孩子不能哭。哭了就重来。”

夏宁的手指收紧，强忍着没有出声。

许南音继续说：“有一个人站在门边，鞋很干净。他不叫我小昭。他说，南边那个音，听钟，不听人。还有一个老伯伯……他拿本子。他的手背有一块黑斑，写字的时候一直挡着最后一格。”

沈昭和顾南枝对视一眼。

周伯。

裴渡立刻从后库带出的袋子里取出半本旧访客簿。簿子外皮已经被雨气浸软，页角发黄，前面几页多是修缮、祭祀、族内访客记录。翻到中段，有几页被刀片割过，只剩窄窄的纸根。

许南音一看到那本簿子，呼吸骤然乱了。

沈昭立刻抬手，让裴渡停住。“不用看。你只听我问，不想答就不答。”

许南音却摇头，眼睛死死盯着纸根。“他拿的不是这个厚本子。是小本。黑皮的。有人进门要写，出去也要写。出去那一栏……不写名字，写谁带走。”

顾南枝立刻记下：“出入双栏，带走人签名。”

周叙白低声说：“祠堂后库有内簿和外簿。外簿给族人和修缮用，内簿只给后库出入。周伯一直说内簿早年水淹毁了。”

沈昭看向他。“你信过？”

周叙白的下颌绷紧。“我没有查到底。”

“不是没查到底。”沈昭的声音冷下来，“是你默认周家祠堂里某些门可以不被查。因为它们披着家族、母亲、祖宗和旧规矩的皮，你每一次要伸手，都会先问自己够不够资格。”

周叙白被她的话逼得沉默。

仓内很静，只有雨水沿破瓦落下。许南音似乎被这份静压住了，忽然用两只手捂住耳朵，喃喃道：“不要让她听见，不要让沈听见。”

沈昭蹲下，隔着一步距离，把掌心摊开在地上。“南音，我在这里。我不会放那卷带子。”

“不是你。”许南音眼里有泪，却没有落下来，“是那个女孩。她在里面哭。她一直说她不姓周。老伯伯说不姓周也要走周门。鞋很干净的人说，先不要让南音听见，她会认错。她认错了，两个都留不住。”

周叙白像被这句话击中，肩背僵住。

沈昭慢慢转头。“鞋很干净的人，是周叙川？”

许南音闭上眼，过了很久，才摇头。“我不知道脸。我只记得他签字的时候，旁边的人叫他川先生。可是本子上写的不是川。写的是周。”

裴渡翻访客簿的手停在半空。

周叙白忽然上前一步，拿过那半本外簿，快速翻到靠后的几页。纸页之间夹着一小段被撕断的黑色封皮，像从更小的本子上扯下来的。封皮内侧粘着半枚红线纤维，下面压着一行浅浅的拓印：

“内访，带出另记。”

顾南枝呼吸一紧：“内簿没毁。有人把封皮撕下来夹进外簿，是故意留线。”

沈昭看向周叙白。“后库还有哪一处能藏内簿？”

周叙白没有立刻回答。他的目光落在那行拓印上，像看见了自己家里另一扇从未真正推开的门。

沈昭站起身，逼近半步。“现在不是让你想周家脸面的时候。许南音被这本内簿带走过。沈页也可能被同一只手签出去过。周叙川的旧签名，周伯的见证，周家的祠堂后库，全在一条线上。你要是还把它当成你家的私事，我就把你从这条线里踢出去。”

周叙白抬眼看她，眼底全是血丝。

“香案后面有一块旧地砖。”他说，“小时候周伯不许任何人踩。何清如有一次站在那里很久，出来后手里有灰。我当时以为她在找祖谱。”

“不是祖谱。”沈昭说。

“不是。”周叙白声音低到发沉，“那下面可能是内簿暗格。”

许南音忽然抓紧外套，颤声说：“不能让老伯伯先回去。他会把出去那一栏烧掉。”

顾南枝立刻拿起电话：“周伯已移交程序车，我让人确认实时位置。”

电话刚接通，她脸色就变了。

押送周伯的程序车在老宅外路口被一辆修缮工程车轻撞，现场没有人员重伤，但周伯借着混乱从车门另一侧被人接走。监控里，接走他的不是周家律师，也不是白衬衫。

是一个撑黑伞的男人。

伞面压得很低，只露出一只干净到没有沾泥的黑皮鞋。

许南音看见画面的一瞬，整个人往后缩了一下，喉咙里挤出一个破碎的音。

“他来拿本子了。”

【本章完】
